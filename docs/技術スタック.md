|---|---|---|
| 言語 | TypeScript | 6.0系 |
| フレームワーク | React | 19.2系 |

## 4. コード品質チェック

| 項目 | 内容 |
|---|---|
| フロントエンド | [oxlint](https://oxc.rs/docs/guide/usage/linter.html)（`.oxlintrc.json`）でReact特有のルール（Hooksのルール違反等）を検出する。`npm run lint`で実行 |
| バックエンド | [Checkstyle](https://checkstyle.org/)（`backend/config/checkstyle/checkstyle.xml`）で未使用import・空catchブロック・文字列の`==`比較等を検出する。`./gradlew checkstyleMain`で実行、`./gradlew check`にも組み込み済み |

## 5. バージョン管理の方針
- フロントエンド（`frontend/package.json`）、バックエンド（`backend/build.gradle`）、データベース（`docker-compose.yml`）が実際のバージョンの一次情報であり、本表はそれに合わせて更新する
- 具体的なバージョンは実装時点（2026年8月）のものであり、今後のライブラリ更新に応じて随時見直す
- 2026年8月にバージョン監査を実施し、以下の方針とした
  - React・Vite・Spring Boot・Javaは当時の最新/LTSのため維持
  - TypeScriptは7.0（Go製ネイティブコンパイラ）がリリース直後で情報が少ないため、当面6.0系を維持する
  - Node.jsは26系（Current、LTS化は2026年10月予定）を使用継続する
  - PostgreSQLは16系が2世代型落ちしていたため18系に更新した
