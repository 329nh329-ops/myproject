# 画面設計

要件定義書に基づく、画面レイアウト・UI要素の詳細仕様。

## 1. 画面構成（イメージ）

```
+--------------------------------------------------------------------+
|  Trello風タスク管理                                                  |
+--------------------------------------------------------------------+
|  未着手 (2件)        |  進行中 (2件)        |  完了 (1件)            |
|  [優先度順][期限順]  |  [優先度順][期限順]  |  [優先度順][期限順]    |
|  ------------------ |  ------------------ |  ------------------   |
|  +----------------+  |  +----------------+  |  +----------------+ |
|  | タイトル         |  |  | タイトル         |  |  | タイトル        | |
|  | 優先度: 高       |  |  | 優先度: 中       |  |  | 優先度: 低      | |
|  | 期限: 2026/09/01|  |  | 期限: -         |  |  | 期限: 2026/08/20| |
|  +----------------+  |  +----------------+  |  +----------------+ |
|  [カード2]           |  [カード4]           |                        |
|                      |                      |                        |
|  ＋ カードを追加      |  ＋ カードを追加      |  ＋ カードを追加        |
+--------------------------------------------------------------------+
```

## 2. 並び替えボタン
- 各リストのヘッダー直下に「優先度順」「期限順」の2つのボタンを横並びで配置する
- ボタンを押すとそのリスト内のカードが指定順に並び替わる（一度きりの整列であり、常時その順序を維持するものではない）

## 3. カード表示要素
- タイトル（1行、長い場合は「…」で省略表示）
- 優先度（文字表示。色分けを行う場合は 高=赤系／中=黄系／低=緑系 とする）
- 期限（未設定の場合は「期限: -」と表示。期限が本日より前の場合は赤字で強調）
- カードをクリックすると4章の編集フォームが開く（削除操作もこのフォームから行う）

## 4. 新規作成／編集フォーム要素
インラインで展開されるフォームは以下の要素で構成する。

| 要素 | 種類 | 備考 |
|---|---|---|
| タイトル入力欄 | テキストボックス（1行） | プレースホルダー「タスク名を入力」 |
| 説明文入力欄 | テキストエリア（複数行） | プレースホルダー「詳細（任意）」 |
| 優先度選択 | セレクトボックス | 選択肢：高・中・低 |
| 期限入力欄 | 日付ピッカー | 未入力可 |
| 保存/追加ボタン | ボタン | 新規時は「追加」、編集時は「保存」と表示を変える |
| 削除ボタン | ボタン | 編集時のみ表示する（新規作成時は対象カードがまだ存在しないため非表示）。誤操作防止のため赤系の配色にし、保存・追加ボタンと視覚的に区別する |
| キャンセルボタン | ボタン | フォームを閉じ、変更を破棄する |
| エラーメッセージ表示欄 | テキスト（赤字） | タイトル未入力時のみ表示 |

編集フォームのボタンは「保存」「削除」「キャンセル」の3つを横並びに配置する。

## 5. ドラッグ＆ドロップ時の見た目
- ドラッグ中のカード：不透明度を下げる（例：opacity 0.5）
- ドロップ可能なリスト領域：ドラッグ中カードが重なっている間、枠線または背景色を変化させる
- 同一リスト内でのドラッグ時は、ドロップ先のカードの位置に応じて並び順が入れ替わる
