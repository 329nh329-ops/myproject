# 機能要件

要件定義書のスコープに基づく、各機能の詳細仕様。

## 1. リスト表示
- 画面に以下3つのリストを横に並べて表示する
  1. 未着手
  2. 進行中
  3. 完了
- 各リストには、そのリストに属するカードを縦に並べて表示する
- リストのヘッダーには、リスト名と、そのリストに含まれるカード件数を表示する

## 2. カードの情報項目
各カードは以下の情報を持つ。

| 項目 | 必須/任意 | 型 | 備考 |
|---|---|---|---|
| タイトル | 必須 | 文字列（1〜50文字程度） | 未入力の場合は保存不可 |
| 説明文 | 任意 | 文字列（複数行、500文字程度まで） | 詳細メモ用 |
| 優先度 | 必須 | 高 / 中 / 低 の選択式 | デフォルト値は「中」 |
| 期限 | 任意 | 日付 | カレンダー入力（`<input type="date">`） |

## 3. カードの新規作成
- 各リストの下部に「＋カードを追加」の操作トリガーを設置する
- トリガーをクリックすると、そのリストの中にインラインで入力フォームが展開される
  - 入力項目：タイトル・説明文・優先度・期限
  - 優先度は初期値「中」が選択された状態にする
- 「追加」ボタンで保存し、フォームは閉じてカードとして表示される
- 「キャンセル」操作、またはフォーム外クリックでフォームを閉じられる
- タイトル未入力で「追加」を押した場合、入力欄を赤枠で強調し、フォーム内にエラーメッセージ「タイトルを入力してください」を表示して保存を中止する

## 4. カードの編集
- カードをクリックすると、そのカードの表示がインラインで編集フォームに切り替わる（新規作成時と同じ入力項目・同じフォーム構成）
- 全項目（タイトル・説明文・優先度・期限）を編集できる
- 「保存」で変更を反映し、「キャンセル」で変更を破棄して元の表示に戻す
- タイトルを空にして保存しようとした場合は3.と同様にエラー表示する

## 5. カードの削除
- 各カードに削除ボタン（ゴミ箱アイコン等）を表示する
- クリック時、`confirm()` による確認ダイアログ「このカードを削除しますか？」を表示し、OKの場合のみ削除する

## 6. カードの移動・並び替え（ドラッグ＆ドロップ）
- カードをマウスでドラッグし、別のリストにドロップすることでリスト間を移動できる
- カードを同一リスト内でドラッグし、任意のカードの位置にドロップすることで、そのリスト内の並び順を自由に変更できる
- ドラッグ中はカードを半透明にする等、操作中であることを視覚的に示す
- ドラッグ中のカードがリスト上に重なっている間、そのリストの背景色を変える等でドロップ可能であることを示す
- ドロップするとカードの所属リストおよびリスト内の並び順が更新され、即座に画面とデータベースに反映される
- HTML5 Drag and Drop API（`draggable`, `dragstart`, `dragover`, `drop` イベント）を用いて実装する

## 7. カードの並び替え（ソートボタン）
- 各リストに「優先度順」「期限順」の2種類の並び替えボタンを設置する
- 「優先度順」を押すと、そのリスト内のカードが優先度（高→中→低）の順に並び替わる
- 「期限順」を押すと、そのリスト内のカードが期限の早い順に並び替わる。期限未設定のカードは末尾に配置する
- 並び替えは実行した時点でのワンタイムの整列であり、以降にカードを追加・編集・ドラッグ操作すると、その並び順は自由に崩れる（常にその順序を維持し続ける機能ではない）
- 並び替えの対象は実行したリスト内のカードのみとし、他のリストには影響しない

## 8. データの永続化
- カードの作成・編集・削除・移動が発生するたびに、バックエンドのAPIを通じてデータベースへ保存する
- ページ読み込み時にAPI経由でデータベースからカード一覧を取得し、画面に復元する
- データベースに登録されているデータが存在しない場合（初回起動時）は、空のリスト状態で表示する
- データ構造の詳細は [データベース設計.md](./データベース設計.md) を参照
- 各カードはリスト内の並び順を保持する項目（表示順）を持ち、移動・並び替え操作のたびにこの値を更新して保存する

## 9. API仕様（概要）
最低限、以下の操作に対応するAPIエンドポイントを用意する（詳細な設計は実装フェーズで決定する）。

| 操作 | 概要 |
|---|---|
| カード一覧取得 | 全カードの情報を取得する |
| カード新規作成 | タイトル・説明文・優先度・期限・所属リストを指定して1件登録する |
| カード更新 | 指定したカードの内容（タイトル・説明文・優先度・期限）を更新する |
| カード移動・並び替え | 指定したカードの所属リスト（ステータス）およびリスト内の並び順を更新する |
| カード削除 | 指定したカードを1件削除する |
